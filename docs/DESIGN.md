## 톤

- 키워드: 깔끔한 · 신뢰감 있는 · 실용적인. 문체는 해요체 하나로 통일한다.
- 여행 "안내 책자"처럼 정보가 먼저 읽히게 한다. 장식·그라디언트·일러스트로 빈 곳을 채우지 않는다.
- 시간·영업 정보는 숫자를 그대로 보여 준다. "확인됨"은 확인 당시 상태일 뿐이라 확인일을 함께 적는다.

## 시각 기준

| 항목 | 값 |
|---|---|
| 주조색 | `--primary` 목포 색(#00648f). 주요 버튼·선택 상태·현재 일차에만 쓴다 |
| 배경 | 흰색 `bg-background` 기본, 구역 구분은 `bg-background-subtle`만 |
| 상태색 | 충돌 = destructive, 확인 필요 = warning, 확정 = success. 색만으로 전달하지 않고 항상 문구를 붙인다 |
| 서체 | Pretendard(`--font-sans`). 제목 text-lg~xl semibold, 본문 text-sm~base, 보조 text-xs 이상 |
| 모서리·그림자 | 카드 rounded-lg + border, 그림자는 떠 있는 요소(메뉴·시트)에만 |
| 아이콘 | 프로젝트 SVG 세트(선 1.5, 둥근 끝). 보편 기호일 때만 |

## 레이아웃

- 모바일 퍼스트, 콘텐츠 최대 폭 `max-w-screen-md`(편집 화면 PC는 `max-w-screen-xl` 2단).
- 목록·일정은 세로 한 줄 흐름(flex-col gap). 카드 그리드는 탐색 화면 같은 2차원 목록에만.
- 주요 동작 버튼은 화면 상단 오른쪽(저장) 또는 폼 맨 아래(다음 단계) 한 곳에 둔다.

## 화면별 메모

### S01 탐색 홈 (첫 화면)

2026-10-27 사용자 요청("남도여행길잡이 참고, 사진 전체 화면")으로 정한 기준이다.

- 첫 화면은 화면을 가득 채우는 명소 사진 슬라이드다(`h-hero`: 화면 높이 전체, 모바일은 하단 탭만 뺀다).
- 홈 맨 위에서는 헤더를 투명하게 두고 사진 위에 흰 글자로 얹는다(2026-10-27 사용자 요청). 조금이라도 스크롤하면 다른 화면과 같은 흰 헤더로 돌아온다.
- 사진 위에 단색 막(`--scrim`, 검정 50%)을 깔고 흰 글자를 올린다. 그라디언트는 쓰지 않는다.
- 제목은 이 화면만 text-3xl, PC는 text-5xl bold로 키운다. 지역·날짜 조건은 흰 카드(rounded-xl, shadow-lg)에 담아 사진 위에 띄운다.
- 사진은 `src/features/explore/lib/hero-slides.ts`에서 고른 명소 6곳이다. 6초마다 넘어가고 점 버튼·멈춤 버튼이 있다. 움직임 줄이기 설정이면 자동으로 넘기지 않는다.
- 남도여행길잡이 사진은 공공누리 제4유형이라 출처("사진: 남도여행길잡이 · 공공누리 제4유형")를 사진 위에 늘 보여 주고 파일은 손대지 않는다.
- 사진을 못 불러오면 브랜드색 바탕에 같은 제목·조건 카드를 보여 준다.

### S09 여행 시작

한 화면 폼: 날짜(시작·종료, 최대 4일) → 지역(선택) → 여행 속도(여유롭게/알차게/정하지 않음) → "코스 만들기".
이동수단은 자동차만이라 선택지 대신 안내 문구로 보여 준다.

### S10 코스 편집

- 상단: 뒤로 · 여행 제목(입력) · 저장. 그 아래 날짜·이동수단 한 줄.
- 일차 탭 → 일차 요약(방문 수 · 이동 합계 · 계산 상태) → 일차 시작·종료 시각 → 시간표.
- 시간표 카드: 도착(대기) · 장소 · 체류 · 출발, 펼치면 영업구간·주문 마감·출발 한도. 고정 프로그램은 "고정" 배지와 시각.
- 카드 사이 구간 행: 자동차 경로 예상 시간·거리 + 접근 여유. 실패 시 "다시 시도".
- 경고 문구는 네 가지로 구분한다: 도착 시 마감 · 다음 일정 지각 · 영업시간 확인 필요 · 경로 조회 실패.
- 더보기 메뉴: 체류 수정 · 위로 · 아래로 · 다른 일차로 · 삭제. 드래그 전용 편집은 두지 않는다.
- 사용자가 정한 순서·시각은 몰래 바꾸지 않는다. 충돌은 이유와 할 수 있는 동작만 보여 준다.
