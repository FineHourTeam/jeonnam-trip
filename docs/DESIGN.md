# 머물전남. 디자인 기준

> 2026-10-17 작성. 근거는 `docs/benchmark/README.md`(트리플·마이리얼트립·원더로그·에어비앤비·대한민국 구석구석·남도여행길잡이·네이버 플레이스 모바일 화면 25장)이다.
> 사용자 지시: "시안을 따르지 않아도 된다, 벤치마킹으로 전문적인 모바일 웹을 만든다". 이 문서가 화면 구현의 구속력 있는 브리프다.

## 1. 브리프

| 항목 | 결정 |
|---|---|
| 인상 | 깔끔한, 신뢰감 있는, 실용적인. 사진은 탐색·보관함에서만 크게, 일정 편집은 시간·이동 정보가 먼저 |
| 주조색 | 황토 `#805117` (`--primary`). 전남 황토에서 따온 색. 주 버튼·선택 칩·진행 중 배지·일정 레일·지도 경로선 |
| 보조색 | 연한 황토 `--primary-soft`(선택 상태·다음 장소 강조). 새 hue는 더하지 않는다 |
| 상태색 | 충돌·휴무·취소 `destructive(-soft)`, 확인 필요·변경 `warning(-soft)`, 확인됨 `success(-soft)`. 상태는 언제나 문구와 함께 |
| 배경 | 흰색 기본. 섹션 구분이 꼭 필요할 때만 `bg-background-subtle` 띠 |
| 서체 | Pretendard Variable. 상세 제목 `text-2xl font-bold`, 섹션 `text-lg font-bold`, 카드 제목 `text-base font-semibold`, 메타 `text-sm text-muted-foreground`, 확인일·출처 `text-xs` |
| 형태 | 카드·사진 `rounded-xl`, 칩 `rounded-full`, 입력·작은 버튼 `rounded-lg`. 그림자는 지도 위에 뜨는 요소에만 |
| 간격 | 좌우 `px-4`, 묶음 안 `gap-3`, 섹션 사이 `gap-8` (4px 그리드) |
| 사진 | 목록 카드 `aspect-4/3`, 행 썸네일 `size-18`, 사진 없으면 `bg-background-subtle` + 종류 아이콘. CC 사진은 저작자 표시 |
| 터치 | 주요 버튼 44~48px (`size="touch"`·`size="xl"`), 아이콘 버튼 `icon-touch` |
| 모션 | `src/lib/motion.ts` 프리셋만. 목록 진입 stagger 정도. 시트·다이얼로그는 컴포넌트 내장 애니메이션 |

## 2. 내비게이션

- 하단 탭바는 최상위 화면에만 둔다: 탐색 · 보관함 · (가운데) 여행 만들기 · 내 여행. 활성 탭만 `text-primary`.
- 상세·편집·공유 화면은 탭바를 숨기고 상단 뒤로가기 바(`PageTopBar`) + 하단 고정 주 버튼(`StickyActionBar`) 하나를 쓴다.
- 진입 팝업·앱 유도 시트·떠 있는 배너는 두지 않는다. 화면을 덮는 건 사용자가 연 시트·다이얼로그뿐이다.
- PC(md 이상)는 상단 내비게이션, 코스 편집은 lg 이상에서 왼쪽 일정 + 오른쪽 지도 분할.

## 3. 화면별 기준

| 화면 | 기준 |
|---|---|
| S01 탐색 | 지역 칩 줄 + 기간 요약 → 여행 만들기 카드 → 이 기간 축제 레일(없으면 같은 지역 장소 제안) → 가볼 만한 곳 그리드 → 크리에이터 코스 레일. 인기 수치를 지어내지 않는다 |
| S02 축제 목록/달력 | 한 줄 칩(필터 시트·기간·진행 상태) + 결과 수. 달력은 월 이동 + 날짜 칸 점 + 고른 날 목록. 목록과 달력은 같은 결과 |
| S03 축제 상세 | 사진(저작자 표시) → 상태 배지·제목·기간 → 날짜별 운영 → 프로그램 → 주차·문의·공식 홈페이지 → 출처·확인일 → 지도 → 주변 장소(직선거리 명시). 하단 고정 "이 축제로 여행 만들기" |
| S04 장소 목록 | 종류 칩 + 상세 필터 시트(세부 종류·분위기·목적·이용 조건). 필터가 바뀌어도 선택 유지. 목록/지도 전환 |
| S05 장소 상세 | "영업 중 · 19:30 주문 마감" 한 줄 + 펼치는 요일표(브레이크타임·휴무). 분위기 태그와 확인된 이용 조건을 따로. 항목별 확인일 |
| S06 보관함 | 저장한 장소 / 장소 연결 전 링크 탭. 여러 개 선택 → 일차 고르기. 저장 해제와 일정 삭제를 다른 동작으로 |
| S07 SNS 등록 | 링크 → 장소 검색·직접 입력(여러 곳) → 태그·메모 → 저장. 장소 없이 링크만 저장 가능 |
| S08 크리에이터 코스 | 순서 기준(영상 등장 순서 등)을 숨기지 않는다. 원본과 개인 사본을 구분 |
| S09 여행 시작 | 날짜(최대 4일)·지역·추천/직접·여행 속도(선택). 이동수단은 자동차 하나라 고르는 칸을 두지 않고 표시만 |
| S10 코스 편집 | sticky 일차 탭 "1일차 10.24 (금)" → 일차 요약(장소 수·이동 합계·계산 상태·충돌 N건) → 레일 타임라인(도착·체류·출발, 영업 구간, 늦어도 시작) → 장소 사이 얇은 구간 행("자동차 23분 · 14km + 여유 10분", 실패 시 같은 자리에서 다시 시도) → 미배치 후보와 이유. 충돌은 카드 안 원인 한 줄 + 동작 2~3개. 자동으로 고치지 않는다 |
| S11 내 여행 | 카드: 제목·날짜·지역·수정일·공유 상태. 저장 전 작성 중인 여행을 맨 위에 |
| S12 공유 | 공개 미리보기 + 빠지는 정보 목록. 받는 사람 화면 맨 위에 "보기 전용" 안내 + 내 코스로 복사 |

## 4. 문구

- 해요체 하나. 버튼은 "~하기"/명사형 12자 이내. 다이얼로그는 [닫기] [동사+하기].
- 빈 화면은 조건 요약 + 동작 하나("10월 24일 · 순천 축제가 없어요" + [조건 초기화]).
- 값이 없는 정보 행은 숨긴다. "--"를 쓰지 않는다. 미확인은 "확인 필요"로 밝힌다.
- 직선거리는 반드시 "직선"을 붙인다. 경로 시간은 "현재 교통 기준 예상"임을 밝힌다.

## 5. 이번에 추가한 토큰 (tokens.css)

| CSS 변수 | 용도 |
|---|---|
| `--primary-soft` / `--primary-soft-foreground` | 선택 상태·다음 장소·진행 중 강조 |
| `--destructive-soft` / `--destructive-soft-foreground` | 충돌·휴무·취소 안내 상자 |
| `--warning-soft` / `--warning-soft-foreground` | 확인 필요·변경 안내 상자 |
| `--success-soft` / `--success-soft-foreground` | 확인됨 배지 |

`knowledge/design-system.md` 토큰 표 반영은 사람이 한다 (knowledge/는 에이전트 쓰기 범위 밖).
